# React User Management Dashboard

Responsive user management dashboard built with React and Supabase PostgreSQL.
Focused on CRUD operations, reusable components and modern frontend architecture.

## Live Demo

https://ialmeida-userpagereact.vercel.app/

## Tech Stack

- React
- JavaScript
- Supabase
- PostgreSQL
- CSS
- Vite

## Features

- User creation and management
- CRUD operations
- Supabase backend integration
- Reusable React components
- Responsive dashboard layout
- Dynamic UI rendering

## Installation

```bash
npm install
npm run dev
```
